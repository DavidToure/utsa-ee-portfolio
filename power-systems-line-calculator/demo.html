Built from Glover problems 5.2, 5.14 and 5.23. Per-phase analysis of a balanced three-phase line. Voltage regulation is (|VS|/|A| minus |VR,full load|) divided by |VR,full load|. For problem 5.2 the nominal-pi results are 269.2 kV, 635 A, 26.4 percent regulation, and 270.8 MW sent, which match my worked solution. The exact model uses Zc = sqrt(z/y), gamma l = l sqrt(zy), A = D = cosh(gamma l), B = Zc sinh(gamma l), C = sinh(gamma l)/Zc.
