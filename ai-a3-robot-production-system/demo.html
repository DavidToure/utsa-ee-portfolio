Robot Navigation Rules

A robot has to reach an object on a grid without hitting obstacles. Each cycle, the facts in working memory trigger rules, and when several rules match, conflict resolution decides which one fires. Step through the cycles, or change the scenario and watch a different path form.

Built from EE 5663 Assignment 3, a rule-based robot from lecture 4. Rules 4, 5, 2, 3 move the robot north, south, west, east, rules 8, 6, 7, 9 turn it away from an obstacle, and rule 1 detects the object. Conflicts are resolved by specificity, then refractoriness, then a fixed random order of n, w, s, e. The engine is a direct port of my MATLAB function and gives the same 22-cycle trace for the homework scenario. Runs stop after 30 cycles.
