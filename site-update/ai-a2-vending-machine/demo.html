Rule-Based Vending Machine

A vending machine for tea, coffee, and hot chocolate, run entirely by IF-THEN rules. It takes coins before it activates the buttons, keeps credit across several drinks, and returns change when you are done. Every action below names the rule that fired.

The rules

  1. Money Rule 1. If a recognized coin is inserted, add its value to M.
  2. Error rule. If a letter is not a coin or a drink, say so and ask again. If stock is empty, refill it.
  3. Drink dispensary rule 1. If M is at least the price, dispense the drink and subtract the price. The rest stays as credit.
  4. Drink dispensary rule 2. If M is less than the price, ask for more coins and check the same drink again.
  5. Change rule. When the customer is done, return M as change and reset it to zero.
Built from EE 5663 Assignment 2. Prices are tea $0.25, coffee $0.50, hot chocolate $0.30. Coins are P ($0.01), N ($0.05), D ($0.10), Q ($0.25), F ($0.50). One shared stock of 20 covers all three drinks. The engine is a direct port of my MATLAB function, with the same rules and messages.
